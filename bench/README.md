# FRamily Hub — the bench

Six standing roles. Every gathering-facing change is checked by each, in this order, before it ships.
The blueprint is the spec: https://claude.ai/artifact/45f2QAiJeQ9ZZnhdpa2M4y

| Role | Brief |
| --- | --- |

| Developer | dev.md |
| Host assistant (AI) | host-assistant.md |

## The workflow (every change)
1. **Ask** — one line, in the host's or guest's words.
2. **Spec** — product lead checks the seven principles; UX puts it on the canvas as a phone frame; copy writes the words (EN + ES).
3. **Build** — dev ships to the live site under a new BUILD number; visual signs off on the look.
4. **Verify** — rendered at 390×844, compared to the frame, tested on Jared's phone with a real number.
5. **Record** — canvas frame updated to match what shipped; blueprint "Live today" row moved.

A change that skips a step waits. Frame and site disagree → fix the wrong one the same day.
